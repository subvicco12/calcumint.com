# Catalog candidate adjudication checklist

This document is review-only. It cannot certify or publish calculators.

For every candidate mapping, reviewers must record the canonical master ID, domain, title, registry slug, calculator ID, immutable version, source path, input constraints, output units, examples, golden fixtures, risk classification, and decision evidence.

Mark a candidate HOLD if another master row uses the same registry slug, if multiple implementations share a title, or if the input/output contract does not establish equivalence. Do not auto-approve on title equality.

Keep Power, Travel Time, Distance, and the six previously held calculator identities under existing governance holds until source-level adjudication is complete.

A reviewed mapping must not change runtime publication, certification, database records, permissions, or deployment settings.
