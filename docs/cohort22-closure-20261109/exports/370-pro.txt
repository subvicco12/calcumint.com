METHODOLOGY
Ideal deterministic arithmetic using decimal MB (1 MB = 1,000,000 octets) and Mbps (1 Mb
ps = 1,000,000 bits/second), eight bits per octet. Strictly positive supplied quantities
; not measured bandwidth, provider speed or a delivery guarantee. Protocol overhead, lat
ency, congestion and changing rates are excluded.\u000aTechnical calculation revision: t
echnology.bandwidth@1\u000a\u000aAverage transfer rate from data size and elapsed time.\
u000aBandwidth (Mbps) = data MB × 8 ÷ time seconds
