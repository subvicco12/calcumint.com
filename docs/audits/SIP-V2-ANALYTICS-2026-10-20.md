# SIP v2 draft analytics — 2026-10-20

RELEASE HOLD. Offline and unregistered; no certification, publication, entitlement, history re-evaluation, or saved-scenario authority is granted.

`buildSipV2DraftAnalytics(rawInput: unknown)` validates and calculates the authored candidate baseline, then independently evaluates scenario offsets -1/0/+1 and sensitivity offsets -2/-1/0/+1/+2. It returns `identity: {id: 'finance.sip', slug: 'sip-calculator', version: 2}`, `baseline: {input, output}`, `scenarios`, `points`, and `unavailable`. Existing analytical panel structural types are imported only as types. Every numeric request uses the v2 candidate; certified v1 adapters and helpers are never called. Signed zero and tiny baseline rates survive request metadata. Labels describe actual requested annual percentage rates; rejected rates are reported without floor clamping. Baseline validation failure throws; an optional request failure leaves the valid baseline visible. Scenario deltas subtract canonical decimal cents exactly and fail closed if the decimal result cannot round-trip through Number.

`solveSipV2DraftGoal({targetFutureValue, annualReturnPercent, termMonths, contributionTiming})` returns the same v2 identity, validated goal input, and output `{monthlyContribution, futureValue, investedAmount, estimatedGain}`. Targets must be finite and strictly positive, matching the authored inverse. The inverse is forward-calculated by the candidate and reconciled against candidate-certified rounded target cents. Unsafe currency precision and unsupported inverse reconciliation throw. Contribution timing is required for goals; baseline timing follows the candidate default.

There is no serializer or record loader. Fresh drafts do not read saved outputs, accept persisted identity envelopes, or alter the saved financial scenario allowlist or history gates. The module has no active application importer. Inputs are parsed into fresh objects and calculations do not mutate caller data. No production, database, migration, UI, registry, workflow, deployment, or publication changes are included.
