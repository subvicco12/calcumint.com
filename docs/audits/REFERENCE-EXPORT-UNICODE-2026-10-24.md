# Supported Unicode labels in deterministic PDF exports

Frozen baseline: `b85e845ecd11856f963c9f32af9634b8e4738293`. Existing runtime-PDF, sprint-P0 PDF/accessibility, final-acceptance ledger and MASTER-PRODUCT-COMPLETION evidence is reused; no broad audit or ledger promotion.

A deterministic INR/scientific-unit report reproduced a functional export gap: Poppler `pdftotext -layout` returned `Savings \u20b9 and resistance \u03a9`, including escaped currency/unit table cells and the raw currency appendix. Those disclosed escape codes preserve identity but do not provide readable supported typography. The new extraction regression failed on that exact expected/received difference before implementation.

The serializer now embeds a deterministic BMP subset of DejaVu Sans Mono only when visible report text requires it, with Identity-H, explicit CID-to-glyph mapping and ToUnicode. Existing Latin-1-only reports retain their standard font path. The subset retains original glyph IDs and fixed monospace metrics; Unicode metadata uses PDF UTF-16BE strings. Characters absent from the font, supplementary-plane characters and controls retain explicit escapes. There is no platform-font lookup, network request or runtime fontTools dependency. `src/lib/pdf-font/` contains license, original-source SHA256 and a reproducible fontTools 4.61.1 generator; runtime font bytes and mappings are checked in.

Mandatory regressions check deterministic bytes, font embedding/mapping, reciprocal existing tags, exact raw numeric values, stream lengths and cross-reference offsets. An independent Poppler test checks readable ₹, Ω, µ and ° text and recognition of embedded font/Unicode mapping. It runs when Poppler is installed and otherwise skips explicitly, so the normal suite does not acquire an undeclared OS dependency. Reproduce with `npm test -- src/lib/calculation-export-pdf-unicode.test.ts src/lib/calculation-export-pdf.test.ts`; install Poppler separately only when independent extraction evidence is required.

This closes the demonstrated supported-label readability defect, not the entire international typography requirement. The font does not cover every writing system or supplementary-plane glyph; shaping/bidirectional layout and complete font embedding across every Latin-only report are not established. Independent PDF/UA validation, physical screen-reader/device acceptance and controlled performance measurements remain unverified. Tagged tables/raw appendix and existing PDF/UA disclaimer remain. No engine, version, mathematical policy, certification, publication, production action or external approval changed.
